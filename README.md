# 📊 Data Cleaning and Preparation using Python & Pandas

## 📌 Overview

This project focuses on cleaning and preparing the **Global Superstore Dataset** using Python and Pandas. Data cleaning is an essential step in the data analytics process, as raw data often contains missing values, duplicate records, and inconsistent formats that can affect analysis results.

The dataset was processed to improve data quality and make it ready for further analysis and visualization.

## 🎯 Objectives

* Load and explore the dataset.
* Identify and handle missing values.
* Remove duplicate records.
* Convert data into appropriate formats.
* Improve overall data quality.
* Export a cleaned dataset for analysis.

## 🛠️ Tools Used

* Python
* Pandas
* Jupyter Notebook

## 🔍 Steps Performed

### 1. Data Loading

Imported the dataset into Jupyter Notebook using Pandas.

### 2. Data Exploration

Examined dataset structure, columns, and data types.

### 3. Missing Value Handling

Identified missing values and handled them appropriately.

### 4. Duplicate Removal

Detected and removed duplicate rows to ensure data accuracy.

### 5. Data Type Conversion

Converted date columns and other fields into suitable formats.

### 6. Exporting Cleaned Data

Saved the cleaned dataset as a new CSV file for future analysis.

## 📈 Key Learnings

* Working with Pandas DataFrames
* Data preprocessing techniques
* Handling missing values and duplicates
* Data type conversion
* Preparing data for analytics projects

## ✅ Outcome

Successfully cleaned and prepared the dataset by improving data consistency, removing unwanted records, and ensuring the data was ready for analysis and visualization.
